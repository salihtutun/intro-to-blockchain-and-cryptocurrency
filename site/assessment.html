Intro to Blockchain and Cryptocurrency

What you will turn in

This course is one project: design a community money, issue it on the class testnet, and show it circulating. The PDFs exist so we can see the design. They are not a second course.

If a word feels hard: open handbook.html for that session (cafeteria / house-key / lemonade pictures). Every class notebook starts with Words we use today and ends with Check you understand. If you can explain the picture to a sharp 15-year-old, you understand it. If you can only say “decentralized,” open the handbook before you write.
